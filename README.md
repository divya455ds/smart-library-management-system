## Overview

An AI-powered Library Management System built with **React** and **Node.js**.  
Users can manage their personal book collections, while admins can analyze library data using natural language queries.

Developed as part of the ** Internship Project 2025**.

---
## ⚠️ Note on Deployment

The backend was previously deployed on Railway, but the free trial has expired.

To run locally:

1. Clone the repository
2. Install dependencies:
   npm install
3. Set up environment variables:
   DATABASE_URL=your_db
   JWT_SECRET=your_secret
4. Run the server:
   npm run dev

## Features

-  Book Management (Create, Read, Update, Delete)
-  User & Admin Management
-  JWT Authentication
-  Responsive Design

### 🤖 AI Features
- Natural language queries (e.g. *“Who owns the most books?”*)
- AI-generated reading summaries & insights
- Optional book recommendations

## Tech Stack

**Frontend**
- React 19 + Vite
- React Router v6
- Axios
- Tailwind CSS

**Backend**
- Node.js + Express
- PostgreSQL + Sequelize
- JWT & Bcrypt
- Groq AI (LLaMA 3.3-70B)
